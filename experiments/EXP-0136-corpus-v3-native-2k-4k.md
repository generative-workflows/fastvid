# EXP-0136: corpus v3 native 2K/4K coverage

Date: 2026-07-27
Status: ACCEPTED

## Hypothesis

Adding native 2K/4K rendered controls and real-world 4K motion will expose GPU
scaling behavior and natural-content failures hidden by the mostly-1080p v2
corpus without changing any existing sample.

## Change

Corpus v3 adds two stills and four 24-frame videos: Spring at 2048x858, Glass
Half at 3840x2160, a 3840x2160 crowd clip, and a 3840x2160 lizard clip. Source
URLs, authors, licenses, input hashes, conversion assumptions, timestamps,
dimensions, and output hashes are pinned.

## Validation

- `bash -n scripts/fetch-corpus.sh`: pass
- `jq empty corpus/manifest.json`: pass
- codec-track manifest count: 14 images, 10 videos
- full `scripts/fetch-corpus.sh`: pass
- generated byte sizes match planar YUV422p8 geometry for all six additions
- existing v2 and high-bit checksum rows: pass during generation
- new derivative SHA-256 values committed in `corpus/derived-checksums.sha256`

## Result

Accepted as the new development corpus. The added media is suitable for
correctness and throughput work. Because the upstream video is already lossy
and two sources omit color metadata, it is not evidence for calibrated-color
or pristine-source quality claims.
